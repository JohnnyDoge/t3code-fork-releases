# T3 Code fork releases

This repository publishes macOS arm64 and Windows x64 nightly builds of the
[T3 Code fork](https://github.com/JohnnyDoge/t3code). Download installers from
[Releases](https://github.com/JohnnyDoge/t3code-fork-releases/releases). Each
nightly's notes link to the source commit used for the build.

Maintain this repository's files in `scripts/fork/release-repo/` in the code
fork. The [operations guide](https://github.com/JohnnyDoge/t3code/blob/main/docs/fork/OPERATIONS.md)
covers setup and manual releases.
